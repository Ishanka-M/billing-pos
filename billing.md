**Role:** Act as a Senior Full-Stack Developer specializing in Serverless and CDN-based web applications.

**Project Title:** Infinite Manage Pro - Advanced Online Sales & Billing Management System.

**Objective:** Build a fully functional, professional-grade Billing & ERP system using ONLY a CDN-based architecture.
**Strict Constraints:** 1. No Node.js, No NPM, No Local Build processes. 
2. Use HTML5, CSS3 (Tailwind CSS via CDN), and Vue.js 3 (via CDN) for a reactive frontend.
3. Database & Auth: Use Firebase (via CDN) or Supabase (via CDN) to handle data storage without a dedicated backend server.

**Modules to Develop for "Infinite Manage Pro":**
1. **Dynamic Dashboard:** Real-time metrics for sales, stock levels, and expenses using Chart.js.
2. **Infinite Stock Control:** Advanced inventory management with SKU tracking, categories, and automated low-stock warnings.
3. **POS / Billing Engine:** - Rapid product search/barcode support.
   - Real-time cart calculation (Tax, Discounts).
   - Instant receipt printing (Thermal/A4 formats).
4. **Financial Suite:** Purchase orders, supplier tracking, and a petty cash/salary management module.
5. **Customer Relations (CRM):** Customer profiles with purchase history and loyalty/credit balance tracking.
6. **Cloud Access:** Multi-device synchronization (Mobile, Tablet, Desktop) using real-time database listeners.

- Brand identity: Use a modern, dark/light mode compatible theme using Tailwind.
- Layout: Responsive sidebar navigation with a sleek, clean workspace.
- Components: Use Modals for data entry and searchable DataTables for records.

**Deliverables:**
1. A complete `index.html` structure or a modular structure using ES modules via CDN.
2. All necessary CDN links (Tailwind, FontAwesome, Vue 3, Firebase, Chart.js).
3. Optimized JavaScript logic to handle business operations locally in the browser.

**Tone:** Highly professional, efficient, and production-ready.
